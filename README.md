# FitLook - Provador Virtual

Projeto desenvolvido para a disciplina de Front-End.

## Páginas do Projeto
- `index.html`: Provador virtual e recomendação de tamanho.

- `planejamento.html`: Apresentação e proposta da ideia.

## Tecnologias
HTML5, CSS3 e JavaScript.
